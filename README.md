🌊 Visit Vizag – Tourism Website

A responsive tourism website showcasing the beauty of Visakhapatnam (Vizag), also known as the City of Destiny.
The website highlights major tourist attractions including beaches, hill stations, waterfalls, and hotels.

🔗 Live Demo:
👉 https://visitvizag.github.io/visitvizag/

🧭 About The Project

Visit Vizag is a frontend tourism website built to promote the scenic destinations of Visakhapatnam, Andhra Pradesh.

The project focuses on:

Clean UI design

Organized content sections

Attractive tourist imagery

Easy navigation between categories

Responsive layout

✨ Features

✔ Beautiful Hero Section with Welcome Banner
✔ Navigation Menu (Beaches, Hill Stations, Waterfalls, Hotels, Contact Us)
✔ Card-Based Layout for Attractions
✔ Explore Buttons for Each Location
✔ Smooth Section Navigation
✔ Responsive Design
